Install guide

Up and running in a minute.

Three steps, then it’s one keypress away for good.

  1. 01

    Choose Portable or an installer

    Run Snapvere-Portable.exe directly or install using Snapvere-Setup.exe or Snapvere-Setup.msi. If Windows says “Windows protected your PC”, click More info → Run anyway only when you trust the publisher and have verified the checksum. Snapvere isn’t code-signed yet.

  2. 02

    Find it in your tray

    Launch Snapvere from the Start menu, or run the portable file. It runs next to the clock — click the icon for your gallery, right-click for capture, recording and settings. It starts with Windows; you can switch that off.

  3. 03

    Capture and record

    PrtSc captures a region and Ctrl + Shift + R records one to MP4 or GIF. Change either in Settings → Hotkeys.

Tip If PrtSc opens the Windows Snipping Tool instead, turn off Settings → Accessibility → Keyboard → Use the Print screen key to open screen capture.
