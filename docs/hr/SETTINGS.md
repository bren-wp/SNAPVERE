# SNAPVERE 0.1.2 postavke

Windows postavke obuhvaćaju lokalne opcije poput pokretanja s Windowsima, uključivanja pokazivača i jezika.

Browser ekstenzije omogućuju samo ponašanje spremanja snimki. Naziv SNAPVERE, wordmark i prefiks spremljenih datoteka nisu korisnički promjenjivi.

Nijedna postavka ne uključuje telemetriju, automatski cloud upload ili udaljeni runtime kod.
