# SNAPVERE 0.1.1 status proizvoda

Aktivne površine proizvoda su **Windows** i **browser ekstenzije**.

Windows ima tray-first rad, region/window/screen capture, lokalne anotacije, copy/save, x86/x64/ARM64 payloadove te universal Setup i Portable pakete.

Chrome, Edge, Opera i Firefox imaju vidljivo, region i ograničeno full-page snimanje. Brand je zaključan na SNAPVERE. CI provjerava build, runtime smoke testove, package lifecycle, dozvole, sigurnosne limite i regresije veličine paketa.
