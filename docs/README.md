# SNAPVERE Documentation

Current maintained product line: **SNAPVERE 0.1.7** for Windows and Chrome, Edge, Opera and Firefox.

This documentation describes the production product surface, its implementation boundaries and the evidence generated by CI. The current public binaries are v0.1.7; later `main` changes may contain explicitly documented unreleased reliability/security/UX hardening. Historical release facts remain in the repository release history instead of being rewritten into current-product documentation.
