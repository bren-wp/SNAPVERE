# SNAPVERE 0.1.2 Settings

## Windows settings

Windows exposes only implemented local preferences, including startup behavior, cursor inclusion and language. Preferences are stored for the current Windows account under `%LOCALAPPDATA%\SNAPVERE`.

## Browser settings

Browser extensions expose only capture behavior such as whether the browser should ask where to save supported captures. The SNAPVERE product identity and filename prefix are fixed and are not user-customizable.

No setting enables telemetry, automatic cloud upload or remote runtime code.
