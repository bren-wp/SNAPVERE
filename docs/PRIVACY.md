# SNAPVERE 0.1.2 Privacy

SNAPVERE is local-first. Core Windows and browser screenshot processing does not require a SNAPVERE account or automatic cloud service.

## Windows

Captured pixels are processed locally. PNG files are saved only when the user requests a save workflow. Startup diagnostics are local, size-bounded and intended for runtime errors; they must not intentionally contain screenshot pixels, clipboard contents, credentials or private signing material.

## Browsers

Browser extensions process capture data locally and use the browser download flow for saved PNG files. The extensions do not include first-party analytics, telemetry, advertising or an automatic screenshot uploader. They do not request broad host access.

External applications or synced folders chosen by the user have their own privacy behavior.
