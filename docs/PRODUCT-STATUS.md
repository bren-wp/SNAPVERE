# SNAPVERE 0.1.1 Product Status

Active product surfaces are **Windows** and **browser extensions**.

## Windows

Production implementation includes tray-first startup, region/window/screen capture, local annotation, clipboard/save workflows, x86/x64/ARM64 payloads, universal Setup and Portable packaging, settings, recent captures and local diagnostics.

## Browsers

Production source is maintained for Chrome, Edge, Opera and Firefox. Visible, region and bounded full-page capture are implemented. Brand identity is locked to SNAPVERE. GitHub release ZIPs are not represented as externally approved store listings unless that publication has actually happened.

## Quality posture

CI covers Windows builds/tests and package lifecycle, browser source/runtime/package validation, product-contract validation, CodeQL and package-size regression budgets. These gates reduce regressions; they are not a claim that software can never encounter a platform-specific defect.
