# SNAPVERE 0.1.1 Branding

**SNAPVERE** is the product name and visible wordmark. **Brendigo** is the developer and publisher identity.

Production Windows and browser surfaces must not expose controls that rename the product, replace the wordmark or change the saved capture prefix to another brand. Browser downloads use `SNAPVERE-<capture-type>-<timestamp>.png`.
